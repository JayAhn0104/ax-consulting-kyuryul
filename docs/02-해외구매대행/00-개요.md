# 02. 해외구매대행 — 개선 지점 탐색

## 문제

아직 구체화되지 않음. 상품 선별·업로드는 부스터로더로 원활히 처리되고 있음.
부스터로더 2.0 출시 후 실제 병목을 관찰할 예정.

## 관찰 포인트

- 부스터로더 출력값(상품명 등)의 네이버 검색 로직 부합 여부. 후처리를 통한 개선 여지
- 등록 단계보다 **주문 이후 단계**에 수작업이 집중되어 있을 가능성
  (타오바오 주문, 배송대행지 검수·결제, 스토어 25개 송장 입력)

## 확인 사항

- [ ] 부스터로더 2.0 출시 시점 및 변경 사항
- [ ] 부스터로더 결과물 중 수작업으로 수정하는 부분
- [ ] 주문 이후 단계 중 가장 부담이 큰 업무 (타오바오 주문 / 검수·결제 / 송장 입력 / CS)
- [ ] shopmine 기능 범위 (주문 수집, 송장 일괄 입력 지원 여부)
- [ ] 배송대행지 업체명 및 소통 방식 (웹 / 메신저 / 엑셀)
- [ ] 반품·교환·오배송 처리 방식
