# 02. 해외구매대행 — 주문 처리 자동화

> 2026-11-25 클라이언트 추가 의견 반영. 미확인 내용은 '(확인 필요)'로 표기함.

## 문제

상품 선별·업로드는 부스터로더로 원활히 처리됨. 수작업 부담은 **주문 이후 단계**에 집중되어 있음.

스마트스토어 주문이 들어올 때마다 타오바오에서 같은 상품을 찾고, 진행 여부를 판단하고, 주문·판매자 문의·배송대행지 신청을 각 사이트에서 직접 처리함. 스토어 25개(사업자 10개)의 주문을 같은 방식으로 처리하므로 주문 건수에 비례해 시간이 늘어남.

## 현재 업무 흐름

| # | 단계 | 업무 내용 | 사이트 | 판단 필요 |
|---|---|---|---|---|
| 1 | 주문 확인 | 스마트스토어 신규 주문 확인 | shopmine, 스마트스토어 | |
| 2 | 상품 찾기 | 타오바오에서 판매 중인 상품과 같은 상품·옵션 검색 | 타오바오 | 동일 상품 여부 |
| 3 | 진행 검토 | 무게, 위험물·통관 제한 품목, 현재 가격(마진), 재고 확인 후 진행 결정 | 타오바오 | **진행 / 취소** |
| 4 | 타오바오 주문 | 옵션 선택, 배송지(배송대행지) 입력, 결제 | 타오바오 | 결제 |
| 5 | 판매자 문의 | 고객 문의 사항, 재고·옵션 확인을 판매자 채팅으로 질문 (중국어) | 타오바오 채팅 | 답변 해석 |
| 6 | 배송대행지 신청 | 주문번호·품목·수량·통관 정보를 배송대행지 신청서에 입력 | 배송대행지 사이트 | |
| 7 | 이후 | 입고 사진 검수 → 포장 옵션·결제 → 국내 발송 → 송장 입력 | 배송대행지, 스마트스토어 | 검수 |

1~6단계는 여러 사이트를 오가며 같은 정보를 옮겨 적는 작업이 대부분임. 3단계(진행 검토)와 4단계 결제는 클라이언트의 판단이 필요함.

## 목표 형태

```
입력:  신규 주문 (스마트스토어 25개)
AI:    같은 상품 찾기 → 검토표 작성(무게·제한 품목·현재가·마진) → 주문 준비
       → 판매자 문의 작성·번역 → 배송대행지 신청서 입력
사람:  진행 여부 결정, 결제 승인, 문의 답변 확인
```

- 클라이언트는 AI가 정리한 검토표를 보고 **진행 / 취소**만 결정하고, 결제를 승인함
- 진행 검토 기준(무게 한도, 금지 품목, 최소 마진)은 기준 문서로 명문화하여 AI가 그 기준으로 판단

## 해결 방향 가설

- **브라우저 AI 에이전트** 적용. 타오바오 구매자 기능과 배송대행지는 사용할 만한 API가 거의 없으므로, 클라이언트가 로그인한 브라우저에서 AI가 직접 조작하는 방식이 적합함
  - 후보: Aside(AI 브라우저), OpenClaw(오픈소스 개인 에이전트, 메신저로 지시) 등. 컨설턴트가 추가 조사 중
- **사람 승인 지점** 고정: 진행 결정, 결제, 판매자에게 보내는 메시지 발송 전
- 지시와 승인은 메신저(텔레그램 또는 Slack)로 받는 방식 검토. [04-고객CS](../04-고객CS/00-개요.md)의 알림 채널과 공유 가능
- 1차는 2~3단계(상품 찾기·검토표)만 자동화하여 정확도 확인 후 범위 확대

## 위험

| 위험 | 내용 |
|---|---|
| 결제 오류 | 잘못된 상품·옵션·수량 결제. 결제는 반드시 사람 승인 |
| 사이트 보안 | 타오바오·배송대행지의 자동화 감지, 추가 인증, 계정 제한 가능성 |
| 정확도 | 동일 상품 판별 오류, 옵션 오선택. 검토표에 근거(이미지 비교·링크)를 함께 표시 |
| 도구 성숙도 | 브라우저 에이전트는 신생 제품이 많아 안정성·지속성 검증 필요 |
| Windows 지원 | 클라이언트 PC는 Windows. 일부 AI 브라우저는 macOS 전용 (확인 필요) |

## 확인 사항

- [ ] 하루 주문 건수 (스토어 25개 합산), 1건당 처리 시간
- [ ] 단계별 소요 시간 비중 (상품 찾기 / 검토 / 주문 / 판매자 문의 / 배송대행지 신청)
- [ ] 진행 검토 기준: 무게 한도, 취급 불가 품목, 최소 마진, 가격 변동 허용 범위
- [ ] 판매자 문의의 주요 유형 (재고, 옵션, 고객 질문 전달 등)과 빈도
- [ ] 배송대행지 업체명, 신청 방식 (웹 / 엑셀 / 메신저)
- [ ] shopmine·부스터로더 기능 범위 (주문 수집, 타오바오 상품 링크 보관 여부, 송장 일괄 입력)
- [ ] 부스터로더 2.0 출시 시점 및 주문 처리 관련 변경 사항
- [ ] 타오바오 결제 수단 및 계정 운영 방식 (계정 수, 인증 방식)
