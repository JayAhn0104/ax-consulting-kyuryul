# 04. 고객 CS — 문의 통합 및 AI 응대

> 2026-11-25 클라이언트 추가 의견 반영. 미확인 내용은 '(확인 필요)'로 표기함.

## 문제

식물 판매(꿈을 심는 정원)와 해외구매대행 모두 고객 문의 응대가 필요하며, 두 가지 부담이 있음.

1. **문의 채널 분산** — 문의가 스마트스토어 고객문의·상품문의, 톡톡, 쿠팡, 전화 등 여러 채널로 들어오고, 구매대행은 스토어가 25개임. 채널마다 따로 확인·답변해야 함
2. **불시 전화** — 작업 중이거나 이동 중에도 전화를 받아야 함. 응대 중 다른 업무가 끊기고, 놓친 전화는 다시 확인해야 함

## 문의 채널

| 채널 | 대상 사업 | 현재 처리 | 연동 수단 |
|---|---|---|---|
| 스마트스토어 고객문의·상품문의 | 식물, 구매대행(25개) | 판매자센터에서 스토어별 확인 | 네이버 커머스API 문의 조회·답변 |
| 네이버 톡톡 | 식물, 구매대행 | (확인 필요) | 톡톡 파트너 API (확인 필요) |
| 쿠팡 고객문의 | 식물 | 쿠팡윙스 | 쿠팡 Open API |
| 전화 | 식물, 구매대행 | 클라이언트가 직접 수신 | 착신전환 + AI 전화 응대 |
| 기타 (카카오톡 채널 등) | (확인 필요) | (확인 필요) | (확인 필요) |

## 목표 형태

```
[문의 통합]  각 채널 문의 수집 → 메신저(텔레그램 또는 Slack)로 일원화
             → AI가 주문 정보를 붙이고 답변 초안 작성
             → 클라이언트가 [승인] / [수정] → 해당 채널에 답변 등록

[전화 응대]  기존 번호 유지, 착신전환 → AI가 수신
             → 주문 조회 · 배송/반품/관리법 안내 · 처리 불가 시 담당자 연결 약속
             → 통화 요약을 메신저로 전달
```

- 답변 등록, 환불·보상 약속처럼 책임이 따르는 응대는 항상 클라이언트 승인 후 처리
- 응대 기준(배송·반품 정책, 식물 관리법, 구매대행 통관·배송 기간)은 기준 문서로 명문화하여 AI가 참고

## 해결 방향 가설

### 문의 통합 (텍스트 채널)

- 채널별 API로 문의 수집 → AI 초안 → 메신저 승인 → API로 답변 등록
- 메신저: 텔레그램(봇 생성 간단, 기록 제한 없음) 또는 Slack(채널·스레드 정리, 무료 요금제 90일 기록). 알림 부분을 분리 설계하여 메신저 교체 가능하게 함
- 범용 에이전트(OpenClaw 등)는 사용하지 않음. 고객이 작성한 글이 AI에 그대로 들어가므로 프롬프트 인젝션 위험이 있어, 권한을 좁힌 전용 흐름으로 구성

### 전화 응대

| 방안 | 내용 | 비고 |
|---|---|---|
| A. 휴대폰 내장 기능 | 갤럭시 빅스비 텍스트 콜, 아이폰 통화 스크리닝 등 | 즉시 시험 가능. 자율 응대·주문 조회 불가 |
| B. 전화 AI 플랫폼 + 자체 응대 로직 | 예: CallBridge. 기존 번호 착신전환, AI 에이전트 수신, 녹취·요약, API·외부 AI 연동, 스마트스토어 주문 조회 지원 | 국내 번호 연결 해결. 월 약 6~8만 원 예상 (월 100통·평균 2분 가정, AI 에이전트 분당 200~300원). 14일 무료 체험 |
| C. 직접 구축 | 국내 인터넷전화(SIP) + 실시간 음성 AI + 자체 도구 | 자유도 최대. 개발·운영 부담, 국내 번호 연결 검증 필요 |

- 피클(Pickle)은 발신 대행 서비스로, 수신 응대 기능은 확인되지 않음
- 1차 검토안: **B안 무료 체험**으로 응대 품질 확인 후 결정

### 실행 환경

- 문의와 전화는 시간과 무관하게 발생하므로 **항상 켜진 클라우드 서버**에서 실행 (상품 등록 웹서비스는 클라이언트 PC 실행)
- 네이버 커머스API IP 제한 → 서버 고정 IP 등록
- AI 비용은 API 사용량 과금 (ChatGPT 요금제 사용 불가)

## 진행 순서 (안)

1. 문의 현황 파악 (채널별 건수, 유형)
2. 문의 통합 1차: 스마트스토어 문의 → 메신저 → AI 초안 → 승인 답변
3. 전화 응대: B안 무료 체험 → 못 받은 전화만 AI 수신 → 통화 요약 메신저 전달
4. 확대: 쿠팡·톡톡 연동, 전화 주문 조회, 전체 전화 AI 우선 수신

## 위험

| 위험 | 대응 |
|---|---|
| 잘못된 안내 | 환불·보상·일정 약속은 AI 응대 범위에서 제외, 담당자 연결 |
| 개인정보 | 주문 조회 전 본인 확인 (주문자명·전화번호 뒷자리). 녹취·요약 보관 기간 설정 |
| 법적 고지 | 통화 시작 시 AI 응대 및 녹음 고지 |
| 프롬프트 인젝션 | 고객 문의를 처리하는 AI에는 조회·초안 작성 권한만 부여. 답변 등록은 승인 후 서버가 처리 |
| 비용 증가 | 통화량에 비례. 월 사용량 모니터링, 요금제 상한 설정 |
