# 03. 사업자 관리

## 문제

사업자 10개, 스토어 25개의 관리 방식에 대한 고민. 구체적인 문제는 아직 정의되지 않음.

## 검토 영역

- 계정·로그인 관리 (사업자별, 스토어별)
- 사업자별 매출·정산·세금 신고
- 스토어별 상품 수 및 한도 현황
- 사업자·스토어 확장 절차
- 플랫폼 정책 리스크

## 확인 사항

- [ ] 관리상 어려움의 구체적 사례 (최근 불편 사항)
- [ ] 사업자별 계정·비밀번호·인증 관리 방식
- [ ] 세무 신고·정산 수행 주체 (직접 / 세무사)
- [ ] 사업자·스토어 추가 확장 계획
