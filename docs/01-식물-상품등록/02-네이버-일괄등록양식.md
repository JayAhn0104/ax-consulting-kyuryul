# 02. 네이버 스마트스토어 — 일괄등록 양식

> 원본: [data/01-식물-상품등록/스마트스토어_일괄등록_양식.xlsx](../../data/01-식물-상품등록/스마트스토어_일괄등록_양식.xlsx) (클라이언트 제공, 네이버 공식 양식)
> 상품 1개가 엑셀 1행에 대응함. AI가 작성한 행을 그대로 업로드할 수 있어 **자동화 출력 형식의 유력 후보**임.

## 양식 구조

- 시트 1개(`일괄등록`), 컬럼 93개
- 1행: 그룹명 (7개, 네이버 공식) · 2행: 항목명 · 3행: 필수 여부 · 4행: 예시 · 5행: 작성 가이드
- 업로드 시 3~6행 삭제

## 발견 사항

**1. 템플릿코드 — 네이버가 제공하는 설정값 기능**
배송비·상품정보제공고시·A/S는 판매자센터에서 템플릿을 1회 생성한 뒤 **템플릿코드만 입력하면** 나머지 컬럼은 무시되고 템플릿 값이 적용됨. [01 문서](01-네이버-등록항목.md)의 '설정' 항목에 해당하는 기능이 네이버에 이미 존재하므로, AI는 해당 영역에서 코드만 입력하면 됨.

**2. 양식에 없는 항목 — 일괄등록만으로는 입력 불가**

| 등록 화면에만 있는 항목                                   | 영향                                                                      |
| --------------------------------------------------------- | ------------------------------------------------------------------------- |
| **태그 / Page Title / Meta description** (검색설정) | 검색 노출용 태그를 엑셀로 입력할 수 없음. 등록 후 화면 수정 또는 API 필요 |
| 상품속성                                                  | 카테고리별 속성 입력 불가                                                 |
| KC인증 등 인증정보                                        | 상품정보제공고시의 '인증허가사항' 텍스트로만 입력 가능                    |
| 노출 채널                                                 | 기본값으로 등록되는 것으로 추정. 확인 필요                                |

**3. 형식 제약 — AI 출력이 준수해야 할 규칙**

- 카테고리·원산지·택배사는 **명칭이 아닌 코드**로 입력해야 함. 코드표 필요 (판매자센터 '찾기' 팝업 또는 API)
- 상세설명은 **HTML**, 이미지는 **URL**로 입력해야 함. 이미지 호스팅 방안 필요
- 복수 값은 줄바꿈·콤마로 구분하는 양식 고유 규칙 존재
- 대표이미지 공식 권장 크기는 640×640으로, 실무 가이드의 1000×1000과 상이함

**4. 클라이언트 운영 방식과의 연관**

- 클라이언트가 말한 '기본할인'은 양식의 **즉시할인(기본할인)** 컬럼에 해당함. 양식상 정율 1~99%까지 입력 가능하므로, 20% 제한은 양식 규칙이 아닌 노출·정책상 제한으로 추정됨. 확인 필요
- 옵션가 설정 범위 규칙 확인됨 (위 표)
