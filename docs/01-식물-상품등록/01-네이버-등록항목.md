# 01. 네이버 스마트스토어 — 상품 등록 항목

> 자동화의 **목표 산출물** 정의. 2026-10-29 기준.
> 네이버 공식 도움말·API 문서는 직접 열람하지 못하여 판매자 가이드·커뮤니티 자료로 교차 확인함. 클라이언트의 실제 등록 화면과 대조 필요.
> 값 뒤의 '(공식)'은 네이버 공식 일괄등록 양식으로 확인된 내용임 ([02-네이버-일괄등록양식](02-네이버-일괄등록양식.md)).

## 범례

> **목표: 모든 항목을 AI가 작성함.** 사람은 원천 정보 입력, 설정값 관리, 최종 검수만 담당.
> '값 근거'는 AI가 각 항목을 무엇에 근거해 작성하는지에 대한 **잠정 분류**이며, 설계 과정에서 변경될 수 있음.

| 값 근거 | 설명                                                                                             | 해당 항목 예                                   |
| ------- | ------------------------------------------------------------------------------------------------ | ---------------------------------------------- |
| 생성    | 사진·상품명·검색 결과를 바탕으로 상품마다 판단                                                 | 카테고리, 상품명, 상세설명, 태그               |
| 설정    | 스토어 설정값(config)을 참조                                                                     | 배송, 반품/교환, A/S, 원산지, 상품정보제공고시 |
| 입력    | 사람이 제공한 원천 정보에 근거. 규칙화되면 AI 작성으로 전환 가능 (예: 판매가 = 매입가 × 마진율) | 사진, 판매가, 재고                             |

입력 형태: 텍스트 · 숫자 · 선택(드롭다운/라디오) · 태그 · 이미지 · 에디터(자유 편집)

## 자동화 관점 요약

```
사람                              AI                                    결과
──────────────                    ──────────────────────────            ──────────────
사진 + 상품명          ──┐
(매입가·재고 등)         ├──▶    [생성] 상품별 판단              ──▶   네이버 등록 항목 전체
                         │        카테고리 · 상품명 · 상세설명                │
설정값 (1회 구축)      ──┘        태그 · 상품속성 · SEO                       ▼
                                  [설정] 설정값 참조                     사람 검수
                                  배송 · 반품 · A/S · 원산지 · 고시
```

- 17개 섹션 중 상품마다 새로 판단해야 하는 핵심 항목은 **카테고리, 상품명, 상세설명, 태그**임. 나머지는 설정값 구축 후 AI가 작성 가능.
- 이 중 **카테고리**와 **상품명**은 문장 품질보다 **네이버 규정 및 검색 결과와의 정합성**이 핵심이므로, 생성 로직보다 조회·검증 로직의 비중이 큼.
- 소요 시간이 가장 큰 항목은 **상세설명**으로 추정됨. 클라이언트 확인 필요.

## 확인 필요

- [ ] 실제 등록 화면과 위 항목의 순서·필수 여부 대조
- [ ] 클라이언트가 참고하는 네이버 상품명 가이드 원문 (링크 또는 캡처)
- [ ] 카테고리 판단 사례 (상품명 → 선택 카테고리 → 선택 근거)

- [ ] 현재 상세설명 제작 방식, 항목별 소요 시간
