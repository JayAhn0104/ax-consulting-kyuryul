# 01. 식물 — 신규 상품 등록 자동화

## 문제

신규 상품마다 네이버·쿠팡 각각의 형식에 맞춰 상품명, 상세설명 등을 직접 작성해야 하므로 시간이 소요됨.
다품종 사업 특성상 등록 속도가 매출 기회와 직결됨.

## 목표 형태

```
입력:  직접 촬영한 상품 사진 + 상품명
출력:  네이버 등록 항목 값 / 쿠팡 등록 항목 값 (플랫폼별 형식 준수)
```

등록처는 네이버 **스마트스토어센터**, 쿠팡 **쿠팡윙스(Wing)**. 플랫폼별 항목 정리:

- [01-네이버-등록항목](01-네이버-등록항목.md) — 등록 화면 기준 항목
- [02-네이버-일괄등록양식](02-네이버-일괄등록양식.md) — 공식 엑셀 양식 분석
- 쿠팡 — 작성 예정

설계: [03-설계](03-설계.md) — 코딩 에이전트 작업공간 + 미리보기 검토 + 커머스API 등록
상세페이지: [04-상세페이지-샘플](04-상세페이지-샘플.md) — 클라이언트 기존 상세페이지 분석
로드맵: [05-로드맵](05-로드맵.md) — PoC 이후 실사용까지 남은 작업
미리보기: [06-미리보기-개선](06-미리보기-개선.md) — 등록 전 중간 검토 화면 개선 계획

## 해결 방향 가설

- 사진과 상품명을 입력받아 LLM(비전)이 플랫폼별 항목을 작성 (상품명, 태그, 상세설명 등)
- 작성 결과는 사람이 검수한 뒤 등록. 등록 단계의 자동화 범위는 별도 결정 (API / 엑셀 일괄등록 / 수동)

## 확인 사항

- [ ] 월 신규 등록 상품 수, 1건당 등록 소요 시간
- [ ] 소요 시간이 가장 큰 항목 (상품명, 상세설명, 옵션, 카테고리 등)
- [ ] 상세설명 제작 방식 (직접 / 템플릿 / 외주)
- [ ] 동일 상품의 네이버·쿠팡 등록 내용 차이
- [ ] 판매 실적이 좋은 상품 페이지 예시 및 원본 사진 샘플 확보
- [ ] 식물 공통 정보(관리법, 배송 유의사항 등) 정리 여부
