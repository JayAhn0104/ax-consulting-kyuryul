# 06. 미리보기 개선 계획

> 2026-10-30 작성·구현. [05-로드맵](05-로드맵.md) 2절 '2단계 검토' 중 중간 검토(등록 전 미리보기)의 개선 계획.

## 목적

네이버 등록 전에 클라이언트가 **결과물과 그 근거를 함께 검토**하고, 대화로 수정을 요청할 수 있게 함.
고객 화면 확인은 등록 후 판매자센터의 네이버 [미리보기]가 담당하므로, 이 미리보기는 **등록 정보·근거·확인 필요 사항**에 집중함.

## 현재 미리보기의 한계

| # | 한계 | 영향 |
|---|---|---|
| 1 | 섹션 구성이 판매자센터와 다름 (일부 섹션 생략·통합) | 최종 확인 단계와 대조하기 어려움 |
| 2 | 근거가 일부 항목에만 표시됨 (카테고리·상품명·가격·이미지) | 태그·SEO·상세설명 등은 왜 그렇게 작성됐는지 알 수 없음 |
| 3 | 확인 필요 사항이 섹션별 검사표에 흩어져 있음 | 무엇을 결정해야 하는지 한눈에 보이지 않음 |
| 4 | 대표이미지 보정본만 표시됨 | 실물과 다르게 보정됐는지 확인 불가 |
| 5 | 넓은 화면 기준 레이아웃 | 모바일에서 확인하기 어려움 |
| 6 | 근거 기록 위치가 정해져 있지 않음 | 도구마다 다른 위치에 기록 (예: Codex는 최상위 `basis.thumbnail`, `basis.tags` 사용) → 미리보기가 읽지 못함 |

## 화면 구성

```
┌ 상단 ─────────────────────────────────────────
│ 상품명 · 진행 단계 (작성 중 / 등록 승인 / 비공개 등록 / 판매 중)
│ [확인 필요] 클라이언트가 결정할 사항 목록
│   - 정가 32,900원은 임시 규칙 → 확정 필요
│   - 높이 정보 없음 → 상세페이지 상품 정보에서 생략됨
│ 검사 결과 요약: 오류 n · 확인 필요 n · 통과 n
├ 본문: 판매자센터 섹션 순서 ─────────────────────
│ 각 섹션 공통 구조
│   값        등록될 값 (복사 버튼)
│   근거      왜 이 값인지
│   출처      생성 / 설정 / 입력
│   검사      해당 섹션의 검사 결과 (문제 있을 때만 펼침)
└──────────────────────────────────────────────
```

### 섹션 목록

판매자센터 등록 화면 순서([01-네이버-등록항목](01-네이버-등록항목.md))를 따름. 설정값으로 채워지는 섹션은 접힌 상태로 표시.

| # | 섹션 | 표시 내용 | 근거 표시 | 기본 상태 |
|---|---|---|---|---|
| 1 | 카테고리 | 1순위 카테고리, 후보 목록, 네이버쇼핑 검색 링크 | 후보별 이유·카테고리 수요, 과거 판단 기록 | 펼침 |
| 2 | 상품명 | 상품명, 글자수 | 구성 요소별 출처(식물명·구성·키워드), 키워드 비교 결과 | 펼침 |
| 3 | 판매가 | 정가, 할인율, 실판매가, 매입가, 배수 | 산출식 (입력 정가 / 임시 규칙) | 펼침 |
| 4 | 재고수량 | 재고 | 설정값 | 접힘 |
| 5 | 옵션 | 사용 여부 | — | 접힘 |
| 6 | 상품이미지 | 대표이미지 **보정본과 원본 나란히**, 추가이미지 순서 | 대표 선택 이유, 보정 지시 내용, 순서 이유 | 펼침 |
| 7 | 상세설명 | 상세 이미지 미리보기 | 문구 출처(입력 정보·일반 관리법·필수 안내 문구) | 펼침 |
| 8 | 상품주요정보 | 원산지, 브랜드·제조사, 상품상태, 미성년자 구매, 부가세 | 설정값 | 접힘 |
| 9 | 상품정보제공고시 | 상품군, 품명·모델명 | 설정값 + 품명 출처 | 접힘 |
| 10~12 | 배송 · 반품/교환 · A/S | 배송비, 반품·교환비, A/S 연락처 | 설정값 | 접힘 |
| 13~14 | 추가상품 · 구매/혜택 조건 | 기본할인 | 설정값 | 접힘 |
| 15 | 검색설정 | 태그, Page Title, Meta description | 태그별 선정 이유, 등록 불가 태그 제외 내역 | 펼침 |
| 16~17 | 판매자코드 · 노출 채널 | — | 설정값 | 접힘 |

## 근거 기록 형식 표준화

미리보기는 아래 위치에서만 근거를 읽음. 에이전트 절차(SKILL.md)와 템플릿(`product.template.json`)에 명시.

| 섹션 | 기록 위치 | 형식 |
|---|---|---|
| 카테고리 | `category.basis`, `category.candidates[]` | 문장 / `{path, code, reason, demand}` |
| 상품명 | `name.basis`, `name.parts[]` | 문장 / `{text, source}` (source: 식물명·구성·키워드·특징) |
| 판매가 | `price.basis` | 스크립트가 기록 |
| 상품이미지 | `images.basis`, `images.representative.original`, `images.representative.edit` | 문장 / 원본 파일명 / 보정 지시 내용 |
| 상세설명 | `detail.basis` | 문장 |
| 검색설정 | `tags[]`, `tag_basis[]`, `seo.basis` | 태그 목록 / `{tag, reason}` / 문장 |

기존 상품(Codex 작성분)의 최상위 `basis.*` 항목은 미리보기 생성 시 해당 섹션으로 옮겨 읽음 (하위 호환).
