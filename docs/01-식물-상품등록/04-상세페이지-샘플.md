## 설계 반영

- 상세 이미지 가로폭을 **780px**로 변경 (기존 설계 860px)
- 상품 기본 정보에 **높이·화분 지름** 항목 추가. 상세페이지 '상품 정보' 영역의 필수 값
- 상세설명 기본 형식은 무늬아이비 샘플 구성을 따름. 작성 결과는 [plant-agent 무늬아이비 사례](../../plant-agent/products/2026-10-29_무늬아이비_1+1/detail.html)

## 핑크국화형 디자인에 대한 검토

- 페이지 전체를 이미지 생성 모델로 만들면 글자 오류가 생기기 쉽고, 수정할 때마다 전체를 다시 생성해야 함.
- 대안: **HTML 템플릿 + 실제 사진 + 정확한 텍스트**로 구성하고 이미지로 변환. 아이콘·레이아웃은 템플릿으로 고정하고, 사진만 이미지 모델로 보정.
- 유의: 생성된 인물·농장 이미지와 "농장에서 정성껏 키워 발송" 같은 문구는 실제와 다르면 표시광고 관련 문제가 될 수 있음. 실제 사실에 맞는 표현만 사용 권장.

## 확인 사항

- [ ] 클라이언트가 선호하는 형식 (무늬아이비형 단순 구성 / 핑크국화형 디자인)
