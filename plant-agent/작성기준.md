# 상품 등록 작성 기준

AI가 상품 등록 정보를 작성할 때 따르는 기준. 섹션 순서는 스마트스토어센터 상품 등록 화면과 같음.
사용자가 채팅으로 기준 변경을 요청하면 이 파일을 고치고 아래 '변경 이력'에 한 줄 남김.

작성 형식 (작성 기준 페이지가 이 형식으로 화면을 만듦)
- `## 번호. 섹션 · 방식` 섹션. 방식은 AI 작성 / 기본 설정 / 자동 작성 미지원
- `### 항목` 섹션 안의 한 줄 (페이지에서 왼쪽 이름). 기본 설정 섹션은 판매자센터 항목 이름을 그대로 씀
- `- 내용` 목록. 'A → B → C'만 있는 줄은 흐름도로 표시
- `1. 내용` 순서가 있는 목록
- `> 문장` 변경 요청 예시
- `[네이버 규칙]` 네이버가 정한 규칙. 바꿀 수 없음
- `[임시]` 클라이언트 확인 전 임시 기준. 확정 필요
- `{{설정 이름}}` 스토어 설정값(config). 페이지에는 실제 값으로 표시됨

## 공통 원칙

- 사용자가 준 정보와 스토어 설정값에만 근거하여 작성. 원산지·크기·화분 규격·구성 수량을 지어내지 않음
- 빠진 정보는 비워 두고 한 번에 모아서 질문
- AI가 정한 항목은 미리보기에 판단 근거를 함께 표시
- 네이버 등록은 항상 비공개로 먼저 진행. 사용자가 판매자센터에서 확인한 뒤 '공개해줘'라고 하면 판매 공개

## 1. 카테고리 · AI 작성

### 선택 범위
- `생활/건강 > 원예/식물` 하위 카테고리

### 판단 순서
1. 같거나 비슷한 식물을 등록한 적이 있으면 그 카테고리를 따름
2. 없으면 식물 특성에 맞는 후보를 1~2개 고름
3. 후보 중 최근 3개월 네이버쇼핑 클릭 수요가 높은 쪽을 선택

### 피할 것
- 클릭 수요가 거의 없는 카테고리 (예: 넝쿨식물)

### 참고
- 기존 방식(네이버쇼핑 검색 시 광고 제외 최상위 상품의 카테고리)은 네이버 검색 서비스 종료(2026-07-31)로 자동 확인 불가. 미리보기의 검색 링크로 직접 비교

> 다육식물은 무조건 다육식물 카테고리로 해줘
> 공기정화식물보다 관엽식물을 먼저 고려해줘

## 7. 상품이미지/동영상 · AI 작성

### 대표이미지
1. 파일명이 '대표' 또는 '썸네일'로 시작하는 사진
2. 보정된 연출 사진
3. 그 외 사진 중 식물 전체(화분 포함)가 보임 → 배경이 깔끔함 → 정사각형 → 해상도 순으로 선택

### 추가이미지
- 전체 모습 → 잎·무늬 근접 → 줄기·화분 등 세부
- 최대 9장 `[네이버 규칙]`

### 보정
- 요청할 때만 진행
- 배경·조명만 변경. 식물 형태·잎 색·무늬·화분은 원본 유지
- 크기·풍성함 과장 금지
- 보정 스타일(배경색, 연출 방식) 미정 `[임시]`

### 사진 크기
- 긴 변 {{image.max_side}}px로 줄여서 등록
- 짧은 변 {{image.min_side}}px 미만이면 알림 `[네이버 규칙]`

### 동영상
- 사용 안 함

> 대표이미지는 흰 배경으로 보정해줘
> 잎 근접 사진을 두 번째로 넣어줘

## 9. 상세설명 · AI 작성

### 형식
- 가로 {{detail.width}}px 이미지 (클라이언트 기존 상세페이지 폭). {{detail.split_height}}px 높이마다 나눠 등록

### 구성 순서
1. 도입 문구 1줄 + 상품명
2. 대표 사진 + 식물 소개 2~3문장 (어디에 두기 좋은지)
3. 나머지 사진
4. 상품 정보: 높이, 화분 지름, 구성 — 입력한 값만
5. 키우는 법: 빛, 물, 온도, 통풍 — 일반적으로 알려진 내용만
6. 안내 사항: 개체별 차이, 반려동물 섭취 주의 등 해당하는 경우

### 디자인
- 무늬아이비 상세페이지 형식. 클라이언트 기존 상세페이지 기준으로 확정 필요 `[임시]`

### 금지
- 입력하지 않은 수치
- 실제와 다른 사진·인물·농장 이야기
- 스크립트·외부 링크 `[네이버 규칙]`

> 안내 사항에 '식물 특성상 잎 끝 갈변이 있을 수 있어요'를 항상 넣어줘
> 키우는 법은 빼줘
