### 1. 입력 준비

- 입력 사진 6장이 앞서 시각 확인한 사진과 파일 내용이 같은 것을 비교로 확인함. 사진 원본·파일명 유지.
- 입력·상품 템플릿을 이 폴더에 복사하여 작성함.
- 사용자 확인값: 송오브인디아 1개, 도매가 12,000원, 높이 50~55cm, 화분 지름 15cm.
- 정가 미제공으로 list_price=0을 유지해 임시 가격 규칙 적용.
- 사용자가 요구한 문구를 상세설명에 그대로 반영. 줄바꿈은 br 태그 사용:
  > 식물 특성상 잎 무늬, 색감, 줄기 수형은
  > 개체마다 조금씩 다를 수 있습니다.

### 2. 이미지

- 최신 절차에는 썸네일이 없으면 대표이미지를 직접 고르도록 되어 있으나, 이번 시험 지시가 우선이므로 대표이미지 미지정.
- 썸네일로 시작하는 사진 없음. 대표이미지 생성·보정·임의 지정 없음.
- `uv run scripts/prepare_images.py` 실행. 추가이미지 순서는 전체 모습(005) → 잎 무늬(002) → 잎 근접(006) → 줄기(003) → 화분(004) → 제공된 연출 사진(001).
- 결과: 대표이미지 없음, 추가이미지 6장. 추가이미지에만 기존 스크립트의 JPEG 규격 변환 적용.
- 정사각형·최소 권장 규격 관련 경고는 없으며 대표이미지 없음 안내만 발생.
- 원본과 다른 이미지를 생성하지 않았고, 상세 도입의 전체 사진은 대표이미지 지정과 별개로 사용함.

### 8. 검증·미리보기

- `uv run scripts/validate.py`: 오류 3건 · 확인 필요 3건 · 통과 17건. 오류 때문에 종료 코드 1 반환.
- 오류: 카테고리 미정 / 카테고리 코드 없음 / 대표이미지 없음. 이번 시험 지시에 따른 의도적인 미입력으로, 임의 수정하거나 검증 결과를 숨기지 않음.
- 확인 필요: 임시 가격 규칙 / 대표이미지 없음 안내(오류와 중복) / API 등록용 스토어 설정 미입력.
- 미입력 설정: 원산지 코드, A/S 전화번호·안내, 배송비 유형, 출고지·반품지 주소록 ID.

- `uv run scripts/render_preview.py`로 이 폴더에 preview.html 생성.
- 앞서 브라우저 자동화의 로컬 file URL 접근이 정책상 차단되어 자동 탭 열기·검수는 반복하거나 우회하지 않음. 결과는 로컬 미리보기 링크로 제공하며 상세 이미지는 로컬 이미지 도구로 검수함.
