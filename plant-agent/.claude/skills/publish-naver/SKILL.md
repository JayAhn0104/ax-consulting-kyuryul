# 네이버 등록 · 판매 공개

등록과 공개는 사용자의 명시적 승인이 있을 때만 실행한다. 등록은 항상 비공개 상태로 먼저 한다.

## 1. 비공개 등록

1. `uv run scripts/validate.py products/<상품>` — 오류가 0건이어야 한다.
   - '스토어 설정' 경고(설정값 미입력)가 있으면 등록하지 않는다. 사용자에게 "스토어 기본 설정이 아직 완료되지 않아 등록할 수 없습니다. 컨설턴트에게 문의해 주세요."라고 안내한다.
2. 사용자 승인을 확인하고 product.json의 `status.stage`를 `approved`로 바꾼다.
3. `uv run scripts/naver_api.py register products/<상품>`
4. `uv run scripts/naver_api.py verify products/<상품>` — 불일치가 있으면 사용자에게 알리고 log.md에 기록한다.
5. 사용자에게 안내한다: "비공개로 등록했습니다. 판매자센터 상품 조회에서 상품번호 ○○○을 확인해 주세요. 이상이 없으면 '공개해줘'라고 말씀해 주세요."

## 2. 판매 공개

1. 사용자가 공개를 요청하면 `uv run scripts/naver_api.py publish products/<상품>`
2. 완료를 알리고 log.md에 공개 일시를 기록한다.

## 오류 대응

- 'API 접근 차단 / IP' 오류: "인터넷 주소(IP)가 바뀌어 네이버 연결이 막혔습니다. 커머스API센터에서 IP를 다시 등록해야 합니다."라고 안내한다.
- 그 외 오류: 오류 내용을 log.md에 기록하고, 사용자에게 쉬운 말로 요약한 뒤 컨설턴트에게 전달하도록 안내한다. 같은 요청을 반복해서 재시도하지 않는다.
